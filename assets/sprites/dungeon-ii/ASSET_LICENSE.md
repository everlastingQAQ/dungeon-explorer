# DungeonTileset II assets

The PNG files in this directory are selected frames from:

- **16x16 DungeonTileset II**, by 0x72
  - https://0x72.itch.io/dungeontileset-ii
- **Dungeon Tileset II Extended**, by Niji
  - https://nijikokun.itch.io/dungeontileset-ii-extended

Both source packs are released under the Creative Commons Zero v1.0 Universal
license (CC0-1.0): https://creativecommons.org/publicdomain/zero/1.0/

The files have been renamed only to describe their role in this game. Player,
monster, relic and scene-object sprites come from these CC0 packs. Terrain is
provided separately by the RGS_Dev CC0 tileset under `assets/tilesets/rgs-cc0`.
